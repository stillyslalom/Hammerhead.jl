Analysis and export

  • Flow analysis: profiles, circulation, gradients and spectra.
  • Image and result I/O: loading, batch processing, native files and table/VTK export.
  • Saved settings: recipes that rerun the same processing on new recordings.
  • Calibrated grids: common-coordinate analysis of PIV and image data.
