benchmark context. Their status statements and future-work suggestions are not
the active plan; outstanding items have been reconciled into the root roadmap.

- `ROADMAP.md` — original Challenge-driven phases and GUI framework rationale.
- `GPU_EXTENSION_PLAN.md` — original backend plan; the core correlation,
  deformation, ensemble, and UQ paths are implemented. Later acceleration
  candidates are tracked in the current roadmap.
- `FEEDBACK_PLAN.md` — implementation record for the completed feedback batches.
- `feedback.md` — original review items resolved by `FEEDBACK_PLAN.md`.

All current work is tracked in [`ROADMAP.md`](../../ROADMAP.md).
