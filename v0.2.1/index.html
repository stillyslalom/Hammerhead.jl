Hammerhead.jl

Hammerhead measures fluid motion from particle images: planar particle image velocimetry (PIV), stereo PIV with camera calibration and self-calibration, and particle tracking (PTV), with uncertainty estimates, statistics and derived quantities. HammerheadGUI provides a desktop workflow for the same analyses.

A synthetic particle pair and its measured displacement field; arrow lengths are enlarged.

A first vector field follows one image pair from particle images to a correlation peak and a complete field, then covers window size, masking and conversion to velocity, using synthetic images.

Install

In Julia 1.10 or later, press ] to enter package mode:

pkg> add Hammerhead

CairoMakie draws the tutorial figures. The desktop workflow is in the separate HammerheadGUI package (pkg> add HammerheadGUI); start Julia with several threads (julia -t auto) and open it with using HammerheadGUI; hammerhead().
